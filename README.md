### ALGO-000140: Deterministic FPTAS for the nonnegative permanent
- **Subfield:** Approximate counting, sampling, and average-case complexity
- **Open:** Approximate the permanent of any nonnegative matrix within relative error \(\varepsilon\), deterministically in time polynomial in input size and \(1/\varepsilon\).
- **Status:** Jerrum–Sinclair–Vigoda supplied a randomized approximation scheme in 2004. Comparable deterministic approximation remains open.
- **Type:** theory
- **Why:** Would derandomize a landmark counting algorithm.
- **Key works:** Jerrum, Sinclair, and Vigoda (2004), *A Polynomial-Time Approximation Algorithm for the Permanent of a Matrix with Nonnegative Entries*.
- **Related:** Statistical physics—perfect-matching partition functions; probability—deterministic sampling substitutes.
